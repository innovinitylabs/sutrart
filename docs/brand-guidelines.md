# PARI Brand Guidelines

PARI is creator sovereignty infrastructure, a cultural provenance protocol, storefront infrastructure, syndication infrastructure, and a marketplace interoperability protocol.

PARI is not a crypto casino, NFT flipping platform, or speculative trading platform.

These standards are immutable protocol branding standards. Do not change these values without an explicit future migration.

## Protocol Identity

- Protocol name: `PARI`
- Protocol version: `v0.1-alpha`
- EIP-712 protocol name: `PARI`
- Design principle: the SVG assets are timeless brand marks. Presentation changes with theme. The assets themselves do not.

## Color System

### Dark Mode

- Background: `#0D0D0F`
- Surface: `#1A1A1D`
- Primary Gold: `#C9A56A`
- Gold Hover: `#D8B57A`
- Bright Text: `#F2EFEA`
- Secondary Text: `#B7B1A8`
- Border: `#2C2C31`
- Glow: `rgba(201,165,106,0.15)`

### Light Mode

- Paper: `#F7F4EE`
- White: `#FFFFFF`
- Primary Text: `#171717`
- Secondary Text: `#686868`
- Accent Dark: `#222222`

## Design Rules

Do not use gradients, glassmorphism, neon, NFT rainbow colors, or crypto blue/purple aesthetics.

The visual direction is museum, archive, auction catalogue, cultural institution, manuscript, and provenance.

Gold indicates significance, not decoration.

## Logo System

Source assets:

- `public/pari-wordmark-final.svg`
- `public/Pari_logo_final.svg`

The SVGs are black, outline-based, and intentionally color-neutral. Do not edit SVG artwork, bake colors into SVG files, create colored SVG variants, create separate dark/light SVG exports, convert outlines into filled shapes, or modify path geometry.

Brand colors are applied through CSS and UI styling. The SVG assets themselves remain unchanged.

## Responsive Usage

- Desktop navigation: wordmark only.
- Mobile navigation: logo mark only.
- Favicon: logo mark only.
- App icon: logo mark only.
- Loading states: logo mark only.
- Footer: logo mark or wordmark, never both.
- Hero sections: choose one asset, never logo mark and wordmark together.
- Marketing sections: choose one asset, never logo mark and wordmark together.

## Outline Preservation

Preserve stroke structure, negative space, and the outline aesthetic.

Never fill enclosed areas, add gradients, add shadows, add glow effects directly to SVG, or simplify paths.
